### 1.2 即时态面板（点按即生效，**不走保存、不受脏守卫管**，仅编辑态挂载）

| 面板 | 动作 | 风险点 |
|---|---|---|
| 回调链接（API） | 生成/重新生成/吊销；有效期选择；链接仅显示一次 | 链接等同 API 密钥 |
| 共享授权 | 开启/关闭分享；授权 URL；访问者名单逐人移除 | |
| 管理的应用（StewardSection） | 只读反查列表（改派在应用详情页） | |

### 1.3 页面级动作与校验

- 动作：返回（脏守卫 attempt）、对话、复制（duplicate）、取消、保存；保存成功跳详情页
- 保存校验链：名称必填 → 内联 MCP JSON 解析错阻断 → 仓库目录名正则阻断（三处都会聚焦滚动到对应分区）
- 非阻断提示：场景装配校验（前端前置，锚点徽标计数 + 分区内 inline + 「去处理→」跨区链接）；后端装备告警（warnings，保存后顶部黄条，复制经路由 state 传入）
- 只读态（被分享者）：只露名称/描述 + 「对话」按钮，明示无权查看配置
- 新建态：不挂载集成/管家区；锚点导航同步隐藏

### 1.4 现有布局骨架

- 桌面（≥md）：sticky 顶栏（h-16）+ 左侧锚点导航（w-56，scrollspy+徽标）+ 内容单列平铺（**无最大宽度**）+ sticky 底部保存栏（h-14）
- 移动（<md）：同顶栏 + chips 横滑分区导航（no-scrollbar，sticky top-16）+ 同底部栏；顶栏「取消/保存」隐藏（底栏兜底），「对话」隐藏，仅剩「复制」
- 原语：FormSection（序号徽标卡）/ FormField（label+hint）/ RadioCard / Segmented / Switch / Checkbox / ConfirmDialog / dirty-guard（beforeunload + 站内 a 拦截 + attempt()）

## 3. 设计原则（架构优先）

1. **按状态模型分层，不按实现历史堆叠**：表单态（受保存管）与即时态（点按即生效）在信息架构和视觉上物理分离——这是本稿唯一的「架构级」挪动。
2. **渐进披露**：常用项在收起态直读（凭证行、仓库 URL 主行已做到）；高危/高级项折叠（内联 MCP JSON、shell git 已做到），本稿延续不新增折叠层级。
3. **错误前置**：所有保存阻断错误 live 校验、live 反映到导航徽标；保存动作只做「汇总确认」不做「错误发现」。
4. **移动端沿用已验证的全站模式**：sticky 顶栏 + chips 横滑 + sticky 底部动作栏 + pb-safe（授权页/09-28 收口已定式），不为本页发明新形态。

## 4. 信息架构（新分区方案）

六分区 → **五表单分区 + 一运行管理带**。挪动仅两处：会话/反馈引用从「资源」并入知识库区；集成/分享/管家合并为「运行管理」。

| # | 新分区 | 内容（↑=从别区挪入） | 状态 |
|---|---|---|---|
| 1 | 基本 | 名称*、描述、场景 | 表单 |
| 2 | 提示词与技能 | System Prompt、技能树、默认 Skill | 表单 |
| 3 | 工具与权限 | 对话模式、工具范围、MCP（内置/连接器/内联 JSON） | 表单 |
| 4 | 资源 | 凭证、Git 仓库、shell git、扩展工作目录（移出会话/反馈引用） | 表单 |
| 5 | 知识库与上下文 | 知识库绑定、独立知识库、自动学习 + ↑会话引用（%）、↑反馈引用（#） | 表单 |
| — | 运行管理（编辑态） | 回调链接（API）、共享授权、管理的应用；标注「即时生效，无需保存」 | **即时** |

- 新建态：1–5 可见，运行管理带隐藏（与现状 integration 逻辑一致）。
- 命名理由：「知识库与上下文」= 三类对话中可引用的资料源（kb_* 查库 / % 引会话 / # 引反馈），语义同族；挪走后「资源」收窄为纯外部资源（凭证/仓库/目录），长度与知识库区趋于均衡。
- 拒绝的激进方案：按「身份/能力/资源/发布」四区全重排——systemPrompt 与技能的绑定性、场景跨区联动会被拆散，收益不抵迁移与回归成本。

## 6. 移动端布局（<768px）

```
┌────────────────────────────┐
│ ← 编辑智能体·code-agent ● ⋯│ ← 顶栏：⋯=Menu(对话/复制)；标题+脏点
├────────────────────────────┤
│ [基本][提示词][工具①][资源]→│ ← chips 横滑 sticky（含红/黄徽标）
├────────────────────────────┤
│ ┌─ 1 基本 ───────────────┐ │
│ │ 名称* [____________]   │ │
│ │ 描述 [_____________]   │ │
│ │ 场景 ○ 代码项目 code-dev│ │ ← RadioCard 移动端单列
│ │      ○ 知识库问答 kb-qa │ │   但紧凑行式（p-2.5）
│ │      ○ 调研 ○ 运维      │ │
│ │      ◉ 不设置           │ │
│ └─────────────────────────┘ │
│  … 2/3/4/5 同式，纵向滚动 … │
│ ┌╌ 运行管理 · 即时生效 ╌╌╌┐ │
│ │ 回调链接   [生成链接]   │ │ ← 子面板改手风琴：
│ │ 共享授权   [开启分享]   │ │   收起态一行「状态+入口」
│ │ 管理的应用 2 个    ›    │ │
│ └╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌┘ │
├────────────────────────────┤
│ ●未保存    [取消] [ 保存 ] │ ← sticky 底栏 + pb-safe
└────────────────────────────┘
```

要点：

1. **顶栏动作收敛为 ⋯ 溢出菜单**（修 P3-#8）：移动端「对话」「复制」进 Menu 原语（menu.tsx 已有），顶栏只留返回/标题/脏点/⋯；桌面不变。避免为塞按钮牺牲标题。
2. **运行管理子面板移动端手风琴化**：收起态一行「面板名 + 状态摘要（如 已配置 ·…x4 / 已授权 2 人）+ 入口箭头」，展开才是完整操作。回调「仅显示一次」的完整链接展示展开后进行，避免误触滚动错过。桌面仍平铺。
3. **凭证行两行降级**（修 P3-#9）：`sm:` 断点以下换行——第一行 勾选+code+配置徽标，第二行 name+去配置；keys tooltip 保留。纯 flex-wrap/纵向 layout 调整，不引新原语。
4. **场景 RadioCard 紧凑化**（修 P3-#10）：移动端 p-3→p-2.5、description 与 title 同行省略；单列但高度减半，首屏能看到场景全组+基本区底部。
5. **chips 徽标与桌面同源**：同样显示阻断错（红）与场景提示（黄）计数。
6. **脏守卫补 popstate 拦截**（修 P1-#2，跨端生效）：dirty 时监听 history popstate，先 pushState 哨兵帧，用户返回手势先弹「丢弃并离开」确认（与 confirm-dialog 文案一致），确认后 history.back 两次真离开。三个编辑器（Agent/Workflow/Trigger）共用 dirty-guard，一处修三处受益。
7. 底部保存栏、chips 横滑、pb-safe 等既有定式不动。
