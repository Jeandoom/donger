# 任务分发

## 步骤

1. 执行智能体登记表、场景词表与路由规则已在系统提示中完整给出，直接使用，禁止读任何文件。
2. 将用户任务与登记表各行的职责/技能/适用任务类型做匹配，选定唯一 agentId；无匹配时按规则第 1 条处理。
3. 按路由规则判定是否需要方案设计确认（requiresDesign）与任务分类标签（taskType）。
4. 按系统提示中的输出契约，在最终回复末尾输出路由 JSON。

## 约束

- 不执行任务本身，不写任何文件。
- 不确定时宁可输出 requiresDesign=true 并在 rationale 说明，由人工在方案门兜底。
