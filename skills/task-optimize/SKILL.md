# 任务优化

## 步骤

1. 阅读触发消息中内嵌的任务材料（审计事件摘要、用户评论、目标智能体及其 skills 清单）。
2. 归纳执行画像：用了哪些工具、哪些步骤反复出错或被驳回、用户评论指向什么不满。
3. 对照目标智能体的 skills 清单与知识库（如有路径则用 Read 查看），定位可修订点：
   - SKILL.md 步骤缺失 / 约束不足 / 自测清单遗漏；
   - KB 内容过时或与实际执行冲突。
4. 产出修订提案：以 diff 形式逐文件给出（`--- 旧` / `+++ 新`），每处修订附一句话理由。
5. 向用户展示提案，等待确认后调用 write_skill / update_kb_registry 落盘（每次写入都会弹审批卡）。

## 约束

- 只优化任务材料中涉及的智能体，不顺手动其他智能体。
- 提案遵循 YAGNI：每处修订都要能追溯到审计证据或用户评论，不臆造改进。
- 用户未确认前绝不写盘。
